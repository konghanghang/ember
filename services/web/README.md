# Ember Web Frontend

> Emby 用户管理系统的 Vue 3 前端服务（Monorepo 架构）

**项目位置**: `services/web/`

## 🎯 技术栈

- **框架**: Vue 3 + Vite
- **UI 库**: Element Plus
- **语言**: TypeScript
- **路由**: Vue Router
- **状态管理**: Pinia
- **样式**: TailwindCSS / Element Plus

## 🚀 快速开始

### 安装依赖

```bash
cd services/web
npm install
```

### 开发模式

```bash
npm run dev
```

### 构建

```bash
npm run build
```
