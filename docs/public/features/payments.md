# 支付与续费

Ember 支持两种主要续费方式：

- 兑换码续期
- 在线支付续期

## 兑换码续期

适合：

- 管理员发放兑换码
- 活动、促销或手工续期场景

用户可在续费中心输入兑换码完成续期。

## 在线支付

适合：

- 用户自助购买订阅天数
- 管理员维护多档续费方案

当前支付能力基于 Stripe 一次性支付。

## 续费中心

续费中心会统一展示：

- 当前会员状态
- 在线购买入口
- 兑换码续期入口
- 支付记录
- 兑换记录

## 注意事项

- 支付是否可用取决于部署时是否配置 Stripe
- 未配置支付时，仍可继续使用兑换码续期
