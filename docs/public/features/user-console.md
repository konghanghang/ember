# 用户控制台

Ember 的用户控制台用于承载用户日常使用的高频能力。

## 主要页面

- 仪表盘
- 求片订阅
- 最近入库
- 播放排行
- 追剧日历
- 续费中心

## 用户能做什么

- 查看账号状态、有效期和到期提醒
- 新建和管理求片订阅
- 查看最近入库内容
- 浏览播放排行
- 关注追剧日历
- 通过兑换码或在线支付续期

## 设计原则

- 统一入口：所有用户功能尽量收敛到 `/console/*`
- 到期可见：即使账号已过期，用户仍能看到续费和状态信息
- 渐进降级：过期状态下保留必要功能，不直接让用户失去上下文
