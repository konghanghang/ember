# 追剧日历

追剧日历用于帮助用户跟踪正在更新的剧集。

## 当前能力

- 查看全局周历
- 查看自己关注的剧集周历
- 关注/取消关注剧集
- 结合 Emby 与 TMDB 数据展示更新状态

## 使用前提

- Emby 配置正确
- 已配置 TMDB API Key

## 说明

追剧日历依赖外部数据源：

- Emby 提供媒体库中的剧集信息
- TMDB 提供剧集季集信息和播出时间

如果这些配置不完整，页面会失去部分能力或无法同步。
