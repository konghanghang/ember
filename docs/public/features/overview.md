# 功能总览

Ember 当前围绕 Emby 用户管理提供以下主要能力。

## 用户与账号

- 注册与登录
- 账号有效期管理
- 到期封禁与续期
- 兑换码注册和兑换码续期

## 管理后台

- 用户管理
- 兑换码管理
- 设置中心
- 活跃会话、设备管理、播放历史、媒体质量盘点

## 用户控制台

- 个人信息与状态查看
- 求片订阅
- 最近入库
- 播放排行
- 追剧日历
- 续费中心

详见：

- [用户控制台](./user-console.md)
- [支付与续费](./payments.md)
- [追剧日历](./tv-calendar.md)

## Telegram Bot

- 账号绑定
- 信息查询
- 兑换续期
- 密码重置
- 搜索与订阅
- 管理通知

详见：

- [Telegram Bot](./telegram-bot.md)

## 支付与集成

- Stripe 一次性支付
- Emby 集成
- TMDB 搜索
- MoviePilot 同步
