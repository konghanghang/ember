# Telegram Bot

Ember 提供 Telegram Bot，既能做通知，也能做用户自助操作。

## 用户侧能力

- 绑定 Telegram 账号
- 查询账号信息
- 兑换续期码
- 重置密码
- 搜索并发起订阅

## 管理与通知能力

- 订阅审批通知
- 新用户注册通知
- 支付成功通知
- 播放排行通知
- 群欢迎消息

## 使用前提

- 已正确配置 Telegram Bot Token 和 Webhook
- API 与 Bot 间的内部密钥一致
- 若需要用户自助操作，用户需先完成绑定
