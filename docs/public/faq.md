# 常见问题

## 1. Ember 和 Emby 是什么关系？

Ember 不是媒体服务器本身，它是围绕 Emby 的用户管理与运营系统。

## 2. 必须使用 Telegram 吗？

不是必须，但如果你启用了 Bot 服务，就需要准备 Telegram 相关配置。

## 3. 可以不用 Stripe 吗？

可以。支付是可选能力，不配置时可以只使用兑换码续期。

## 4. 可以不用 MoviePilot 吗？

可以。不配置时，求片相关的自动同步能力会关闭。

## 5. 公开文档和仓库里的内部文档有什么区别？

这套 `docs/public/` 只面向用户和部署者。仓库其余 `docs/` 目录还包含内部架构、方案设计、归档和协作规则，不作为公开发布内容。
