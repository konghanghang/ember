# 快速开始

这份文档只给你最短路径，用来快速判断 Ember 是否适合你，以及如何开始部署。

## Ember 能做什么

- 管理 Emby 用户账号与到期时间
- 支持开放注册或兑换码注册
- 支持兑换码续期与在线支付
- 支持 Telegram Bot 绑定、查询、兑换和通知
- 支持求片订阅、播放排行、追剧日历等能力

## 最短部署路径

1. 准备好 PostgreSQL、Emby 和可访问的域名/回调地址
2. 按 [部署说明](./deployment.md) 启动 `docker-compose.yml`
3. 按 [配置说明](./configuration.md) 补齐必填配置
4. 打开 Web 页面并验证 API 与 Bot 健康状态
