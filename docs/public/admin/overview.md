# 管理后台

管理后台面向管理员，用于管理账号、配置和运营能力。

## 主要模块

- 用户管理
- 兑换码管理
- 设置中心
- 活跃会话
- 设备管理
- 播放历史
- 媒体质量盘点
- 方案与支付记录

## 管理员能做什么

- 管理用户状态和有效期
- 创建和维护兑换码
- 查看系统配置并更新运行期设置
- 监控播放、会话和设备活动
- 管理付费方案和审计支付记录
