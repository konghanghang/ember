# Ember v2.1.5

## 本次更新

本版本改善播放网关的会话连续性与 115 加速稳定性，完善缺集扫描、资源下发和历史工单管理，整合兑换码管理入口，并升级 Axios 修复已知安全问题。

## 重点功能

- 缺集管理支持单条及批量删除已入库、已忽略工单，每批最多 100 条；未收口工单禁止删除，整批校验失败时不执行部分删除。删除只影响工单，不删除媒体或 MoviePilot 下载任务。
- 缺集聚合列表默认展示“待跟进”工单，可显式查看全部或历史状态；扫描部分失败时展示失败对象并支持定向重试，避免把不完整扫描显示为全部成功。

## 问题修复

- 播放网关保留并受限继承客户端明确的起播意图，使用客户端原始会话关联播放租约，改善内部 PlaybackInfo 补查后播放事件与租约错配的问题；内部补查不自行授予或延长新增转存许可。
- 持续播放时，同一已确认活跃或暂停会话可复用尚未到安全截止时间的直链，减少因本地十分钟缓存窗口到期而重复解析的问题；跨会话媒体新鲜度检查和每次身份、配额校验继续生效。
- 为缺少 `Static` 的 `original.mp4` 请求增加受限适配，要求匹配有效本地 MP4 播放证明与身份参数；不接受转码、选流或未知参数，不按客户端名称直接放行。
- 115 源账号成功探测后可正确结束冷却；源路径查询及每次源片段读取增加五秒预算，超时回退 Emby，不继续尚未开始的秒传。Redis 读写遵守调用方剩余超时，减少转存记账等待。
- 缺集资源下发增加跨实例互斥并先保存下发意图。网络异常等导致结果未知时保留待确认状态，要求核对 MoviePilot 后显式重发，降低重复下发风险；扫描异常或取消后仍尝试记录终态并释放锁。
- 修正缺集聚合查询的筛选时序、明细展示和失败反馈，避免旧响应覆盖新结果；结果收缩时分页可回退到有效页。
- 排行榜媒体库读取失败时保留原选择并提供重试，禁止把读取失败误当成空配置保存；修复日期控件溢出和遮挡相邻按钮的问题。
- Axios 从 `1.19.0` 升级至 `1.20.0`，更新锁文件，修复本次审计命中的 Axios 安全公告。

## 体验优化

- 兑换码与兑换记录整合到计费中心；旧兑换中心及兑换码、记录链接自动跳转到对应分段并保留其他查询参数。
- 控制台 115 页面复用账号摘要中的可用用量统计，减少重复查询；刷新失败清除旧统计，不将不可用状态显示为零。
- 完善 115、Redis 和播放回退诊断信息；回退日志明确区分“已返回响应头”与实际播放完成，避免误判播放成功。

## 升级说明

- 相比 `v2.1.4`，没有新增数据库 migration、模型字段、配置项或环境变量，无额外手工 SQL 步骤。最低直接升级支持版本仍为 `v1.6.0` / `2026-06-05` schema 截点；API 启动期继续负责支持窗口内的自动迁移。
- 从 `v2.1.2` 或更早版本升级时，会包含 `v2.1.3` 引入的排行榜批次迁移。升级前备份数据库，并阅读 [v2.1.3 升级说明](./v2.1.3.md#升级说明)；不能只切换旧镜像就假定数据库回退完成。从 `v2.1.1` 或更早版本升级时，还需阅读 [v2.1.2 升级说明](./v2.1.2.md#升级说明)中的新增转存许可和 STRM-only 回退边界。
- API、Web、Bot 默认镜像更新为 `v2.1.5`；API 与 Gateway 必须使用同一个 `EMBER_API_IMAGE`。在 `.env` 或 Compose override 中固定镜像的部署需同步更新覆盖值，保持既有密钥不变。
- Gateway 的进程内播放证明、会话关联和直链缓存会在重启后重新建立。升级前由内部补查会话建立的旧租约不会自动迁移，遇到占用或事件关联异常时应停止并重新起播。
- 删除已忽略工单会同时移除该记录的扫描抑制依据，后续扫描可能重新生成缺集工单；需要持续忽略的记录应保留。
- 使用缺集聚合 API 的外部调用方需注意：未传状态时默认查询 `OPEN` 范围，需要历史数据时显式传 `ALL` 或指定状态。下发结果未知的工单应先核对上游任务，再使用显式重试及版本条件重发。

## 已知限制与验证边界

- 本次发布准备复用同一会话的 Go 测试（显式排除 `Integration`）、`go vet ./...` 和播放网关、DirectPlay、115 账号/配额、缺集服务竞态测试，全部通过；普通 `go build ./...` 本轮重跑通过。
- Axios 升级后 Web 301 项测试通过、3 项集成测试跳过，类型检查与生产构建通过；生产依赖审计为 0 项漏洞，包含开发依赖的全量审计仍有 20 项告警，未在本版本自动修复其他依赖。
- 发布代码基线 `49a6d69` 的 [GitHub CI](https://github.com/konghanghang/ember/actions/runs/37172285102) 已成功，其中 Web 任务执行通过，API/Bot 因路径过滤跳过；此前 `a29dcd3` 的三个预览镜像构建成功，但不包含随后提交的 Axios 升级。
- Bot 源码和依赖相比 `v2.1.4` 未变；本轮已在 Python `3.11.15` 的项目 `.venv` 中完成语法检查、依赖一致性检查及 77 项测试，全部通过。本机未安装 Docker，维护者明确同意本轮跳过本机 Compose 解析检查；已检查默认镜像版本及 API/Gateway 镜像引用一致性，该检查不等同于 Compose 解析校验。
- 本轮未执行真实 PostgreSQL 集成、真实外部系统调用或播放器验收。Infuse 会话连续性、SenPlayer 受限 MP4 适配、115 CDN 完整响应头/Range/字节行为仍需目标环境确认；已有 fake/mock 结果不代表这些实际链路已验收。
- 正式发布前必须确认目标版本三个正式镜像工作流全部成功；部署环境还需使用实际配置完成 Compose 校验，并检查 API 启动期 `[Migrate]` 日志。
