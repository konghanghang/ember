# Ember v1.6.3

## 本次更新

本版本聚焦订阅审核策略、媒体库模板同步状态和配置读取稳定性，包含两份新的顶层 SQL migration，并补齐了对应的 API / Web / Bot / 集成测试闭环。

## 重点功能

- 支持按套餐分组配置“每日自动通过订阅数”，额度内的订阅会直接通过并进入现有 MoviePilot 下发链路。
- 分组媒体库模板支持“仅保存模板”与“保存并同步现有用户”两种模式，用户与管理员都可以对单个账号主动执行“同步到 Emby”。
- 播放排行榜媒体库 allowlist 已稳定落地，最新榜、历史榜、预览生成和 Telegram 通知统一按配置口径计算。

## 问题修复

- 修复排行榜在切换媒体库 allowlist 后，实体归属缓存仍沿用旧范围结果，导致错榜或空榜的问题。
- 修复分组媒体库模板内容未变化时仍递增版本、误打 `out_of_sync` 状态、误创建同步批次的问题。
- 修复 `settings` key cache 在失效与并发读取交错时可能回填旧值的竞态问题。

## 体验优化

- 管理员订阅列表可区分“自动通过”和“人工通过”，自动通过链路同时补齐用户通知与管理员只读通知。
- 控制台账号中心和管理员用户页的媒体库同步动作语义更明确，状态提示与按钮行为一致。
- 仓库测试入口统一收口为 `scripts/test/all.sh`，API / Web / Bot 单测和集成测试可一次跑通。

## 升级说明

- 本版本包含两份新的顶层 SQL migration：
  - `20260707_01_subscription_plan_group_auto_approval.sql`
  - `20260707_02_plan_group_media_library_deferred_sync.sql`
- 从 `v1.6.2` 升级到 `v1.6.3` 无需手工执行 SQL；按现有部署流程 `docker compose pull && docker compose up -d` 即可，由 `ember-api` 启动期 Migrate 自动应用。
- 当前直接升级支持起点仍为 `2026-06-05` / `v1.6.0` 截点；旧于该截点且未执行过已归档增量的数据库，仍需先人工对齐到支持起点 schema。
- Docker Compose 默认镜像 tag 已同步更新为 `v1.6.3`。
