# Ember v1.6.2

## 本次更新

本版本聚焦播放排行榜可用性、控制台展示细节和 Bot 内部调用稳定性，没有引入新的数据库 schema 变更。

## 重点功能

- 播放排行榜新增媒体库 allowlist，可在后台限定参与统计的 Emby 媒体库范围。
- 排行榜页面同步重做信息结构与配置交互，支持直接查看当前统计范围并管理媒体库选择。

## 问题修复

- 修复 Bot 调用 TMDB 搜索内部接口时的鉴权回归，恢复相关搜索链路。
- 修正续期时间展示，补齐对应边界测试，避免文案时间与实际续期结果不一致。
- 修复过期用户场景下控制台首页概览统计被错误清空的问题。

## 体验优化

- 优化播放排行榜页面布局，增强榜首信息、榜内统计和空状态展示。
- 优化媒体库配置弹窗的可读性，补充当前已选范围反馈。

## 升级说明

- 本版本不包含新的顶层 SQL migration。
- 从 `v1.6.1` 增量升级到 `v1.6.2` 无额外手工升级步骤。
- Docker Compose 默认镜像 tag 已同步更新为 `v1.6.2`。
