# 手工测试清单

这不是历史报告，也不是“全量点点点”。它是一份按变更范围选择的手工回归清单。

## 测试前准备

- 使用隔离测试环境，不要拿生产 Emby 和生产 Bot 乱试
- 确认本轮涉及的外部配置已经补齐：Emby、TMDB、Telegram、MoviePilot、支付
- 先完成编译级验证，再做手工检查
- 如果改了 Bot Webhook，本地联调优先看 [Cloudflared 本地联调](./cloudflared-local-testing.md)

## 通用冒烟

每次只要改了运行逻辑，至少做这几项：

- [ ] `GET http://localhost:8080/health` 返回 200
- [ ] 如果改了 Bot：`GET http://localhost:8000/health` 返回 200
- [ ] Web 首页或主入口页可打开
- [ ] 受影响服务日志中没有持续刷屏错误

## 按变更范围选跑

### 1. 鉴权与账号生命周期

适用：登录、注册、续期、过期封禁、账号状态相关改动

- [ ] 管理员登录成功
- [ ] 普通用户登录成功
- [ ] 错误凭据返回正确错误
- [ ] 注册 / 兑换 / 续期后用户状态符合预期
- [ ] 过期用户在管理端与 Emby 状态一致

### 2. 管理后台

适用：管理员页面、列表、设置页、表单保存相关改动

- [ ] 目标页面可打开
- [ ] 列表能加载数据
- [ ] 关键操作按钮可执行且有反馈
- [ ] 保存后刷新页面，数据仍保持一致

### 3. Emby / TMDB / MoviePilot 集成

适用：媒体库、播放记录、追剧日历、搜索、求片审批相关改动

- [ ] Emby 连通性正常
- [ ] 目标接口能拿到真实数据
- [ ] 缺少配置时返回明确错误，而不是静默失败
- [ ] 若改了 MoviePilot，同步成功与失败路径都至少跑一遍

### 4. Telegram / Bot

适用：绑定、菜单、通知、搜索、Webhook 相关改动

- [ ] Bot `/health` 正常
- [ ] `INTERNAL_API_SECRET` 一致时内部调用成功
- [ ] 绑定码 / `/bind` 流程可用
- [ ] `/info`、`/redeem` 等受影响命令可用
- [ ] 新增或修改的通知能实际发到目标聊天

### 5. 支付

适用：方案管理、支付创建、回调、到期延长相关改动

- [ ] 方案列表可读写
- [ ] 创建支付会话成功
- [ ] 成功回调后状态更新正确
- [ ] 支付失败或取消时有可追踪记录

### 6. Docker / 部署

适用：Compose、环境变量、Dockerfile、镜像、启动顺序相关改动

- [ ] `docker compose up -d` 可启动
- [ ] 所有目标服务进入健康状态
- [ ] Web、API、Bot 端口与容器日志正常
- [ ] 关键环境变量缺失时，错误能被直接看见

## 推荐手工回归矩阵

### API-only 改动

- [ ] API 编译与测试通过
- [ ] 通用冒烟
- [ ] 跑本次修改涉及的业务流

### Web-only 改动

- [ ] Web 构建通过
- [ ] 打开受影响页面
- [ ] 核心交互至少点一遍

### Bot-only 改动

- [ ] Bot 语法检查通过
- [ ] Bot `/health`
- [ ] 至少跑一条真实命令或真实通知链路

### 配置或部署改动

- [ ] 通用冒烟
- [ ] `docker compose ps`
- [ ] 至少一条真实业务流
